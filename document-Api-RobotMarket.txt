----------------------------------Login System APIs--------------------------------------------
1. Login with Password

    Possible Roles
        admin
        operator
        viewer
        factory

    Endpoint :
    POST /api/login

    Request Body :
        {
          "username": "09123456789",
          "password": "admin123"
        }

    Response:
        200 Authorized:
        {
          "success": true,
          "token": "jwt_or_session_token",
          "role": "admin",
          "isFirstTime":"true", // new add
          "canRetry": true // new add
        }

    Error Responses :
        401 Unauthorized:
        {
          "success": false,
          "msg": "Invalid username or password",
        }


2. Send OTP Code

    Endpoint:
    POST /api/send-otp
    ارسال کد یکبار مصرف (OTP = One Time Password) برای ورود.

    Request Body :
        {
          "username": "09123456789"
        }

    Response :
        200:
        {
          "success": true,
          "msg": "OTP sent"
        }

    Error Responses :
        400:
        {
          "success": false,
          "msg": "Invalid phone number"
        }

        429:
        {
          "success": false,
          "msg": "429 Too many requests"
        }

        450:
        {
          "success": false,
          "msg": "450 Failed to send OTP"
        }


3. Verify OTP:

    Endpoint :
    POST /api/verify-otp

    Request Body:
    {
      "code": "1234"
      "CAPTCHA": "54321"
    }

    Response :
    200:
    {
      "success": true,
      "token": "jwt_or_session_token",
      "role": "admin"
    }

    Error Responses:
    401:
    {
      "success": false,
      "token": "Invalid OTP"
    }
    410:
    {
      "success": false,
      "token": "OTP expired"
    }


    4. Password Reset Status
    Endpoint:
    GET /reset-status

    Response:
    reset or waiting
    
    reset: دستگاه ریست شده و می‌توان به صفحه لاگین برگشت
    waiting: هنوز دکمه نگه داشته نشده

    Error Responses:
    500 Failed to read reset status

# نام بخش
Device Information

# Endpoint
/api/info

# Method
GET

# Auth Required
Yes

Header
Authorization: Bearer <token>


# Description
این API اطلاعات کلی دستگاه، وضعیت اتصال WiFi در حالت Station، اطلاعات Access Point داخلی دستگاه و داده‌های مورد نیاز داشبورد را برمی‌گرداند.

از همین Endpoint می‌توان هم برای داشبورد و هم برای صفحه اطلاعات دستگاه استفاده کرد.


# Response

    json
        {
          "wifi_sta_ssid": "Home_WiFi",
          "wifi_sta_ip": "192.168.1.45",
          "wifi_sta_connected": true,
          "mac": "AC:67:B2:14:9F:3C",

          "wifi_ap_ssid": "Device_Setup",
          "wifi_ap_ip": "192.168.4.1",
          "wifi_ap_connected_devices": 2,

          "rssi": -58, 

          "esp_version": "1.3.2",
          "stm_version": "2.0.4",
          "board_version": "3.0.7",
          "esp_chip": "ESP32-C3",
          "stm_chip": "STM32F103",
          "SN": "404000",

          "heap_used": 187520,
          "heap_total": 327680,
          "flash_used": 1048576,
          "flash_total": 4194304,

          "system_status": "online",

          "last_operation": {
            "title": "اتصال موفق به WiFi",
            "time": "2026-06-20T10:30:00Z",
            "status": "success"
          }

# Field Descriptions

code_version
نسخه نرم‌افزار دستگاه که در صفحه اطلاعات دستگاه نمایش داده می‌شود.

chip_id
شناسه چیپ یا شناسه یکتای سخت‌افزاری دستگاه.

wifi_sta_ssid
نام شبکه WiFi که دستگاه در حالت Station به آن متصل شده است.

wifi_sta_ip
IP دریافت‌شده توسط دستگاه در شبکه WiFi اصلی.

wifi_sta_connected
وضعیت اتصال دستگاه به WiFi.

true یعنی متصل
false یعنی قطع

mac
آدرس MAC دستگاه.

wifi_ap_ssid
نام شبکه Access Point که خود دستگاه ایجاد کرده است.

wifi_ap_ip
IP دستگاه در حالت Access Point.

wifi_ap_connected_devices
تعداد کلاینت‌ها یا دستگاه‌های متصل به Access Point داخلی دستگاه.

rssi
قدرت سیگنال WiFi بر حسب dBm.

firmware
نسخه Firmware دستگاه.

esp_version
نسخه Firmware یا نرم‌افزار بخش ESP.

stm_version
نسخه Firmware میکروکنترلر STM.

esp_chip
مدل چیپ ESP.

stm_chip
مدل چیپ STM.

serial
شماره سریال دستگاه.

free_heap
مقدار حافظه RAM آزاد بر حسب Byte.

heap_total
کل حافظه Heap در دسترس بر حسب Byte.

flash_used
مقدار حافظه Flash استفاده‌شده بر حسب Byte.

flash_size
کل حافظه Flash دستگاه بر حسب Byte.

system_status
وضعیت کلی سیستم.

مقادیر پیشنهادی:
online
warning
error
offline

last_operation
اطلاعات آخرین عملیات مهم دستگاه.

last_operation.title
عنوان آخرین عملیات.

last_operation.time
زمان آخرین عملیات با فرمت ISO 8601.

last_operation.status
وضعیت آخرین عملیات.

مقادیر پیشنهادی:
success
warning
error
pending

# Authentication

یکی از روش‌های زیر باید توسط سرور پشتیبانی شود.

## روش 1: Query Param
اتصال WebSocket همراه با توکن در Query

ws://<host>/ws?token=<authToken>


## روش 2: ارسال توکن بعد از اتصال

Client پس از اتصال پیام احراز هویت ارسال می‌کند.

json
{
  "type": "auth",
  "token": "<authToken>"
}

نکته
اگر WebSocket روی ESP32 محدودیت در ارسال Header داشته باشد، استفاده از Query Param ساده‌تر است.


# Client Behavior

پس از اتصال موفق، سرور لاگ‌های سیستم را به صورت Real-Time برای کلاینت ارسال می‌کند.



# Message Format

json
{
  "type": "log",
  "timestamp": "2026-06-18T14:30:45Z",
  "level": "info",
  "message": "سیستم راه‌اندازی شد"
}


# Field Descriptions

type
نوع پیام

در این Endpoint مقدار آن برابر با:
log

timestamp
زمان ثبت لاگ (فرمت ISO 8601)

level
سطح لاگ سیستم

مقادیر مجاز:
info
warning
error
debug

message
متن لاگ
